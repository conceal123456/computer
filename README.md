## 怎么运行
双击 index.html（图表/三维库已随文件夹内置）

## 怎么搬进参赛作品「观乎天文」
1. 打开 index.html 看懂结构（全部内联，无外部依赖）
2. 把对应 CSS/JS 段落抄进主作品，套用主作品 token：`--bg:#070b14 / --gold:#d8b45a / --cinnabar:#c8503c`
3. 数据换成本队校准值并附出处标注
