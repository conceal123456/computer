# 观乎天文 · 从二十八宿到中国空间站（参赛原型 v0.1）

> 4C 中国大学生计算机设计大赛 · 冲国一作品骨架
> 零外部依赖：无 CDN、无网络字体、无图片素材——**断网双击 index.html 即可演示**

## 运行

- 方式一：双击 `index.html`
- 方式二：`python -m http.server 8137` 后访问 `http://127.0.0.1:8137/`
- 应急模式：`index.html?static=1` —— 跳过所有动画只画一帧（现场设备卡顿/录屏/打印时用）

## 智能体协作产出（2026-09-27 集成）

三个子智能体并行交付并已集成进 index.html：
- **数据组**：28 宿距星坐标经 SIMBAD J2000 逐条校准（抓出并修正「张」宿 14.1° 大偏差），产物在 `data/mansions-calibrated.json` + `data/校准说明.md`，已灌入 MANSIONS 数组
- **开场组**：`fragments/splash-水墨星尘.html` —— 夜山三层+金尘粒子+盖章动效的开场过场（点击「进入观星台」/Esc 退场，派发 splash:done）
- **动效组**：`fragments/苍龙转场.html` —— 七宿点亮+连线生长的章节转场（自动淡出，派发 dragon:done）
- 片头编排：开场 →（splash:done）→ 苍龙转场 →（dragon:done）→ 星图；右下角「跳过片头」随时可跳
- fragments/ 内两个文件也可单独双击预览

## 参考与借用说明

- `echarts.min.js`、`three.min.js`、`OrbitControls.js` 复制自参考项目「筑韵千年」的离线库（ECharts 为 Apache-2.0，three.js 为 MIT，可自由使用）
- 「数字带出处标签」的版式学自筑韵千年主屏（公开统计/数字示意 pill）
- 前后端分离的标杆是「砚池云览」（Vue3 前端 + proxy/ Node 后端转发大模型），完整代码在 `../05-参考代码/`
