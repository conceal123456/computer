# 二十八宿距星坐标校准说明

> 数据组 · 观星台团队　|　校准日期：2026-09-27　|　适用文件：`data/mansions-calibrated.json`（供 `index.html` MANSIONS 数组集成）

## 一、校准对象

`index.html` 中 `MANSIONS` 数组的 28 个条目，仅更新 `ra`（赤经，小时）与 `dec`（赤纬，度）两个字段；`n / x / s / c / t` 五个字段及条目顺序保持原样，未改动 `index.html` 本身。

## 二、校准方法

1. **历元与坐标系**：一律采用 J2000.0 历元、ICRS 坐标系（与 HYG 星表、Gaia 数据一致，可直接对接后续 HYG 校准工作）。
2. **主数据源**：对每颗距星按 Bayer 命名（如 `alf Vir`、`ups01 Hya`）查询 CDS **SIMBAD** 数据库（simbad.cds.unistra.fr），取其 "ICRS coord. (ep=J2000)" 字段。所查 28 条记录质量标志均为 **A**（位置精度毫角秒级，来自 Gaia DR2/DR3（2020yCat.1350....0G）或 van Leeuwen 2007 依巴谷归算（2007A&A...474..653V））。
3. **交叉验证**：对差异明显的条目（奎 η And、胃 35 Ari、鬼 δ Cnc、井 μ Gem、张 υ¹ Hya）及昴星团，另以英文维基百科条目 infobox 交叉核对，两源全部一致。
4. **舍入规则**：RA 保留 2 位小数（0.01h ≈ 0.15°），Dec 保留 1 位小数（0.1°），最大舍入误差约 0.09°，远小于 ±0.3° 目标精度。
5. **偏差定义**：`偏差` = 原坐标与新坐标的球面角距（球面余弦定理，RA 差按实际角度计入，脚本计算）。
6. **距星约定**：沿用作品原设定——氐宿取 α² Lib（Zubenelgenubi 主星）、牛宿取 β¹ Cap（Dabih 主星）、毕宿取 Aldebaran、参宿取 ζ Ori（参宿一）、昴宿取星团 M45 中心。

- **张（υ¹ Hya）14.1°**：原 RA 10.83h 偏东近 1 小时。υ¹ Hydrae 实际位于 9h51.5m（Alphard 以东、以南），修正后星—张—翼的 RA 序列（9.46 → 9.86 → 11.00）恢复单调。
- **胃（35 Ari）4.5°**：原 RA 3.06h 偏东。35 Arietis 实际位于 2h43.5m（Hamal 与 41 Ari 之间）。
- **鬼（δ Cnc）3.3°**：原 Dec 21.5° 偏北。δ Cancri（Asellus Australis，鬼宿积尸气 M44 旁）实际赤纬 +18.2°。
- **奎（η And）2.0°**：原 RA/Dec 均偏（0.82h、24.4°）。η Andromedae 实际位于 0h57.2m、+23.4°。

## 六、精度自检

- 目标精度 ±0.3°：舍入误差 ≤0.09°，昴宿中心取值散布 ≤0.2°，全部达标。
- JSON 文件共 28 个条目，字段名与示例一致（n/x/s/c/ra/dec/acc/note），可直接被前端脚本读取替换 MANSIONS 的 ra/dec。
